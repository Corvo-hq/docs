Corvo settings and integrations belong to a workspace. Use the switcher at the top of the sidebar to move between workspaces or create one. Each workspace has its own members, integrations, agent settings, and investigations.

## Invite a member

1. Open **Members** in the workspace sidebar.
2. Under **Invite**, enter the person's email address and choose **Viewer**, **Editor**, or **Admin**.
3. Select **Send invite**. The page lists pending invitations separately from members. Invitation links work for seven days; sending another invite to the same address replaces the earlier link.

An admin can change a member's role or remove access from **Members**.

## Choose a role

| Role | Access |
| --- | --- |
| Viewer | View workspace data and use the agent. |
| Editor | Viewer access plus managing instructions, skills, memory, and MCP servers. |
| Admin | Editor access plus managing members, integrations, and agent permissions. |

Grant Admin only to people who should control connected accounts and the agent's allowed operations. See [Agent permissions](/how-corvo-works/agent-permissions) for the separate Git and GitHub switches.
