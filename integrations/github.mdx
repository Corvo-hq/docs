GitHub setup has two stages. The **Corvo GitHub App** determines which repositories may be accessed. **Agent environment** selects the repositories Corvo prepares for agent runs.

## Install the Corvo GitHub App

1. Open **Integrations → GitHub**.
2. Select **Install the Corvo GitHub App**.
3. Choose the GitHub account and the repositories the App may access. An organization may require administrator approval.
4. Return to Corvo and check for **CONNECTED**.

Use **Add or configure repositories** to change the App installation later. Giving the App access to every repository does not add every repository to the agent environment.

## Prepare the agent environment

1. In **Agent environment**, select **Add repo** and choose a repository available to the App. Repeat for each repository Corvo should use.
2. Enter a setup command for each repository. Corvo runs it from the repository root on a clean machine with Node, Git, and `gh`. Install the package manager and dependencies your project needs. For example, a pnpm repository may use:

   ```sh
   npm install -g pnpm
   pnpm install --frozen-lockfile
   ```

3. Select **Save & build**. Corvo runs each setup command and prepares an environment snapshot.
4. Wait for **READY**. Runs start from that snapshot and fetch the latest code.

If setup fails, read the log for the affected repository, fix its command, and run **Save & build** again. After changing repositories or setup commands, rebuild the environment so the next run uses the new configuration.

## Review a fix PR

A completed investigation can report findings without changing code. If the agent opens a PR, review the proposed change and test results in GitHub. The [Permissions](/how-corvo-works/agent-permissions) page controls Git and GitHub operations separately from the App installation.
