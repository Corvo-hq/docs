An admin can bind one Discord alert channel to a workspace. One Discord server belongs to one Corvo workspace. The same bot posts alerts and answers questions.

## Invite the bot and choose a channel

1. Open **Integrations → Discord**.
2. If the bot is not in your server, select **Invite bot** and complete Discord's authorization flow. Return to Corvo and select **Check again**.
3. Select your server, then the channel that should receive investigation alerts. Only channels where the bot can post appear in the list.
4. Select **Save channel**.

The card should now show **CHANNEL BOUND**. The displayed identifier records the selected server and channel.

## Verify the connection

In a channel on that server where the bot has access, mention Corvo and ask a question. It should reply in the same channel. When an investigation alert arrives in the bound alert channel, use **Reply** on that message to open its investigation thread. See [Discord conversations](/features/discord) for the two interaction paths.

Discord takes priority over Telegram for investigation alerts and daily report delivery. Telegram conversations still use the bound Agent bot.

## Change the channel or troubleshoot

Select **Disconnect**, then choose and save the new server and channel. If a server is missing, confirm that the bot has joined it and that it is not bound to another workspace. If a channel is missing, check the bot's permission to view and send messages there, then select **Refresh**.

If the bot can post alerts but cannot open an investigation thread, check its permissions to create public threads and send messages in threads.
