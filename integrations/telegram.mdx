---
title: "Telegram"
description: "Connect chat and alerts bots to a workspace DM or group."
---

Open **Integrations → Telegram bot**. Each workspace has one active Telegram chat destination, either a direct message or a group. The chat bot handles conversations; the separate alerts bot posts investigation updates.

## Connect a direct message

1. Select **DM**, then **Direct message**.
2. Open the Telegram link or scan the QR code.
3. Start the chat bot in Telegram before the displayed token expires.
4. Return to Corvo and confirm the chat destination is connected.
5. Follow the prompt to connect the alerts bot to a DM or group if you want investigation posts.

## Connect a group

1. Select **Group**, then choose the group connection option.
2. Add the chat bot to the group through the displayed Telegram link. If the bot is already there, send the binding command Corvo shows in that group.
3. Return to Corvo and confirm the group is connected.
4. Connect the alerts bot to the destination that should receive investigation posts.

To change from DM to group or back, select **Disconnect** on the existing destination before connecting another. If Corvo does not confirm a connection, reopen the flow for a fresh link or binding command.

See [Telegram conversations](/features/telegram) for chat commands and [Daily reports](/features/daily-reports) for scheduled summaries.
