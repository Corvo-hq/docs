title: "Daily reports"
description: "Review the previous 24 hours of errors and their handling."
---

A daily report summarizes the previous 24 hours of error activity. It groups related errors, shows occurrence counts and handling status, and includes available Cloud Logging or PR links.

## Schedule delivery

Open **Settings → Daily report** in your workspace. Choose a **Timezone**, turn on **Scheduled push**, and set a **Push time**. Leave Scheduled push off if you only want reports on demand. The workspace's timezone determines the local calendar day used in report history.

<Frame caption="Set the timezone and local push time in Settings.">
  ![Daily report settings with Timezone and Push time](/assets/screenshots/report-schedule.webp)
</Frame>

Reports use the same delivery order as investigation alerts: the bound Discord channel first, then the Telegram Notify bot, then the Telegram Agent bot as a fallback. Telegram destinations can be a DM or group. You can also read the report in Corvo.

## Request and read a report

When the Agent bot is bound to a DM, send `/daily_report` in that DM to generate a report on demand. This command is not supported in groups. If generation is already running or a cooldown applies, follow the bot's response before asking again.

Open **Daily reports** in Corvo. **Report history** lists the newest reports first, one per local calendar day. Open a report to read its time range, summary, and error groups. Follow a group's **Pull request** or **Error log** link when available. A **PR OPEN** label means the proposed fix still needs review.
