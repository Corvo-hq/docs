# 與團隊共同使用 Corvo

Workspace 是為共同管理 Corvo 的團隊所規劃。成員、整合與共用設定都會集中在同一處。

這項功能即將推出。以下內容是目前規劃，Workspace 功能現階段尚未開放使用。

## 邀請團隊成員

邀請成員加入 Workspace，並指派 Admin、Editor 或 Viewer 角色。各角色的詳細權限會在規格確定後補上。

## 共用整合

GitHub App 連線將屬於 Workspace。成員會使用該 Workspace 已設定的整合。

一個 GCP 專案或其他資料來源同一時間只能連接至一個 Workspace，同一資料來源不會在多個 Workspace 之間共用。

## 在工作流程中保留 Telegram

Telegram 私訊與群組對話仍會是工作流程的一部分。Workspace 設定預計會顯示目前連接私訊的帳號。
