## 傳送告警

Cloud Logging 日誌接收器依最低嚴重程度，以及所選的 Cloud Run、GKE 或 Compute Engine 資源篩選項目。接收器的 Writer 身分將符合條件的項目發布至 Corvo 的 Pub/Sub 目的地。Corvo 在[告警收集時段](/zh-Hant/how-corvo-works/investigation-pipeline)彙集項目，再分派至調查。

Inclusion filter 決定哪些日誌會離開專案。在來源選擇器選取上層項目，也會包含日後新增的下層資源。

## 調查讀取權

`corvo-agent` 服務帳戶位於你的專案中，具有設定時所選的讀取角色。Corvo 的執行身分在該帳戶上取得 **Service Account Token Creator** 授權後，可取得短期 Token 讀取調查證據，不需要下載服務帳戶金鑰。

接收器 Writer 的發布權限與 `corvo-agent` 的讀取角色彼此獨立。停止串流會移除 Writer 發布至 Corvo 目的地的權限，不會刪除接收器或讀取角色。詳細操作請參閱 [Google Cloud 設定](/zh-Hant/integrations/google-cloud)。
