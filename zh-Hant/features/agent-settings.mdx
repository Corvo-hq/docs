## 新增自訂指示

在側欄開啟 **Agent**，找到 **Custom instructions**。以 Markdown 輸入團隊指示，然後選擇 **Save**。

<Frame caption="自訂指示會套用至工作區的 Agent；編輯後按 Save。">
  ![Custom instructions 編輯區，顯示團隊指示與 Save 按鈕](/assets/screenshots/agent-instructions.webp)
</Frame>

這些指示會套用至 Agent 的對話、告警調查與 PR 回覆。這裡適合寫工作方式；服務與團隊的長期事實請放在[記憶](/zh-Hant/features/memory)。Agent 仍會遵循既有的安全規則與工具限制。

例如：

```text
提出修正方案前，先閱讀 docs/runbooks/。
每份 PR 說明都要列出受影響的服務與驗證結果。
檢查近期變更時，使用團隊的部署分支。
```

若要控制允許的 Git 與 GitHub 操作，請使用 [Agent 權限](../how-corvo-works/agent-permissions)。

## 管理技能

**Skills** 區列出 Agent 可依任務讀取的操作程序。必要的內建技能會保持啟用；其他內建技能可開啟或停用。若要建立自訂技能，選擇 **Add skill**，填寫 **Name**、**Description** 與 **Instructions**，儲存後用開關決定是否啟用。自訂技能也可編輯或刪除。

<Frame caption="Description 說明適用情境，Instructions 列出執行步驟。">
  <img src="/assets/screenshots/agent-skill-dialog.webp" alt="Add skill 視窗，以 Cloud Run 回復版本為例" width="600" />
</Frame>

請在技能中說明適用情境與操作步驟。技能只提供工作指引，不會額外授予 Git、GitHub 或外部工具權限。

## 連接 MCP 伺服器

MCP 伺服器會提供 Corvo 可呼叫的外部工具。Corvo 支援透過 HTTP 或 SSE 連接遠端伺服器。

1. 在 **Agent** 中找到 **MCP servers**，然後選擇 **Add server**。
2. 輸入 **Name** 與伺服器的 **URL**。
3. 選擇該伺服器支援的驗證方式。
4. 完成連接並確認狀態。

<Frame caption="依伺服器支援的方式選擇 OAuth 或 API headers。">
  <img src="/assets/screenshots/agent-mcp-dialog.webp" alt="Add MCP server 視窗，顯示名稱、URL 與驗證選項" width="500" />
</Frame>

名稱只能使用小寫英文字母、數字與連字號，且必須以英文字母或數字開頭。

### OAuth

選擇 **OAuth**，再選擇 **Save & connect**。Corvo 會檢查伺服器；需要授權時，系統會開啟登入流程。不需要登入的伺服器可以直接建立連線。

完成服務提供者的授權後回到 Corvo，確認連線狀態。

### API Headers

選擇 **API headers**，輸入伺服器要求的 Header 名稱與值。先選擇 **Test connection** 檢查存取，再選擇 **Add** 儲存伺服器。

編輯已儲存的伺服器時，未修改的 Header 值會保留原值。若要更新，請輸入新的值。

## 管理連線

使用伺服器的開關啟用或停用連線。進入編輯畫面可以更新設定或測試存取。

**AUTHORIZED** 代表 OAuth 授權已完成。**CONNECTED** 代表連線檢查成功。若顯示 **ERROR** 或 **AUTHORIZATION REQUIRED**，請先處理該狀態再使用工具。

## 了解外部工具的存取範圍

MCP 工具會使用已連接的伺服器與其憑證。Git 與 GitHub 的權限開關不會限制這些外部呼叫。請確認 MCP 服務提供者取得的存取權符合團隊需求。

## 疑難排解

如果 Corvo 無法連接伺服器，請檢查 URL 及服務狀態。需要授權時，請完成登入流程。如果伺服器不支援 Corvo 的 OAuth 流程，請改用該服務支援的 API Header 驗證方式。
