每日報告彙整過去 24 小時的錯誤活動，將相關錯誤分組，列出發生次數、處理狀態，以及可用的 Cloud Logging 或 PR 連結。

## 設定定期傳送

在工作區開啟 **Settings → Daily report**，設定 **Timezone** 與傳送至 Telegram 的 **Push time**。若只想手動要求報告，Push time 可以留空。報告歷史紀錄會依工作區時區對應的當地日期顯示。

## 要求並閱讀報告

在已連接的 Telegram 對話 Bot 傳送 `/daily_report`，可要求即時產生報告。若系統正在產生報告，或仍在冷卻時間內，請依 Bot 的回覆稍後再試。

在 Corvo 開啟 **Daily reports**。**Report history** 以新到舊排序，每個當地日期顯示一份報告。開啟報告可查看涵蓋時段、摘要及錯誤群組。若群組提供 **Pull request** 或 **Error log** 連結，可用來檢查修正或原始日誌。**PR OPEN** 表示修正提案仍待審查。
