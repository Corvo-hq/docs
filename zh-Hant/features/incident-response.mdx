從工作區側欄開啟 **Investigations**。每列是一項調查，可能包含多筆原因相同的告警。**Active** 顯示執行中的調查，**Needs attention** 顯示執行失敗的調查，**Done** 顯示已完成的調查；**All** 顯示全部狀態。Corvo 收集新告警、等待調查時段結束時，頁面可能顯示 **Collecting**。

## 閱讀調查內容

選擇一列，開啟對話與詳細資料欄。詳細資料欄包含：

- **Alerts**：依錯誤分組的告警，以及各筆原始日誌。
- **Pull requests**：這項調查已記錄的 PR；若沒有 PR，會顯示空狀態。
- **Agent summary**：Agent 最近一次的處理摘要。
- **Links**：對應日誌的 Cloud Logging 查詢連結。

對話會顯示調查過程與結果。若工作區顯示訊息輸入欄，你可以在這裡追問，後續對話會沿用同一項調查。新告警在完成分派前，可能暫時沒有可用的對話。

**Done** 只代表最近一次處理已結束，不代表服務已修好。調查可能產生報告、PR，也可能失敗。請閱讀結果並審查 PR，再決定是否部署。

調查頁面上線前的舊告警可能列在另一個歷史區塊。你仍可查看過去的對話；新的追問請在目前的調查中進行。

## 準備程式碼存取

連接 GitHub，並在 [Agent environment](/zh-Hant/integrations/github) 準備 Corvo 需要的儲存庫。Corvo 可根據調查證據找出對應儲存庫，不需要舊版的 Cloud Run 服務與儲存庫綁定。建立分支、推送及開啟草稿 PR 的能力，另受 [Permissions](/zh-Hant/how-corvo-works/agent-permissions) 控制。

告警如何進入調查、重複錯誤如何處理，請參閱[調查流程](/zh-Hant/how-corvo-works/investigation-pipeline)與[重複告警](/zh-Hant/how-corvo-works/deduplication)。
