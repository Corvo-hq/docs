## 安裝 GitHub App

1. 開啟 **Integrations**，然後在 GitHub 卡片選擇 **Manage**。
2. 選擇 **Install the Corvo GitHub App**。
3. 選擇 App 可以存取的帳號與儲存庫。
4. 完成 GitHub 授權並回到 Corvo。

確認 Corvo 顯示已連接的帳號及預期的儲存庫。組織政策可能要求管理員核准安裝。

## 變更儲存庫存取權

在 GitHub 整合頁面選擇 **Add or configure repositories**，檢查並調整授予 App 的儲存庫。

GitHub App 提供 Corvo 執行儲存庫操作時使用的 Bot 身分。Agent 可執行的操作也取決於 [Agent 權限](../how-corvo-works/agent-permissions)。

## 將 Cloud Run 服務綁定至儲存庫

綁定表單位於 **Google Cloud 整合**頁面。

1. 找到 **Bind services to their GitHub repos**。
2. 輸入 **Cloud Run service name**。
3. 輸入 **GitHub owner** 與 **Repo**。
4. 選擇 **Bind**，並確認產生的對應關係。

GitHub App 必須能存取所選的儲存庫。若未設定綁定，告警流程只會回報調查發現。

## 疑難排解

### 安裝需要核准

請 GitHub 組織管理員核准安裝要求。核准後回到 Corvo，確認整合狀態。

### 無法連結安裝項目

從 Corvo 重新開始安裝，並使用可以存取該安裝項目的 GitHub 帳號。已連接至其他 Corvo 帳號的安裝項目無法重複綁定。

### 沒有出現修正 PR

檢查服務對應、儲存庫存取權與 Agent 權限。調查完成後不一定會產生程式碼變更。
